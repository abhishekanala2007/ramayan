# 🙏 Maha Ramayan - Interactive Learning App

An interactive web application to explore the epic Ramayana with bilingual support (Telugu & English).

## ✨ Features

- 📖 **Ramayan Epics** - All 6 Kandas (books) with detailed stories
- ❓ **Quiz for Kids** - Educational quizzes about the epic
- 🌟 **Daily Tasks** - Parent-child activities based on virtues from the Ramayana
- 🔊 **Audio Support** - Listen to stories in Telugu and English
- 🎨 **Beautiful UI** - Dark theme with animated particle background

## 🚀 How to Use

1. Visit the website: [https://abhishekanala2007.github.io/ramayan/](https://abhishekanala2007.github.io/ramayan/)
2. Navigate through the three tabs:
   - **Ramayan Epics** - Learn about all 6 Kandas
   - **Quiz for Kids** - Test your knowledge
   - **Daily Parent-Child Tasks** - Practice daily virtues

## 🎓 The Six Kandas

1. **Bala Kanda** - Birth and childhood of Lord Rama
2. **Ayodhya Kanda** - Rama's exile from Ayodhya
3. **Aranya Kanda** - Life in the forest
4. **Kishkindha Kanda** - Alliance with Sugriva and Hanuman
5. **Sundara Kanda** - Hanuman's epic journey to Lanka
6. **Yuddha Kanda** - The great war and victory

## 💻 Technology

- Pure HTML5, CSS3, and JavaScript
- No external dependencies
- Responsive design for mobile and desktop
- Web Speech API for audio playback
